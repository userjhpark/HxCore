# HxCore  
## .NET 기반 공통 코어 라이브러리 (Common Core Library)

---

## 📌 프로젝트 개요 (Overview)

**HxCore**는 C#/.NET 기반 응용프로그램에서 공통적으로 사용되는  
**유틸리티, 데이터 모델, 환경 설정, 리소스 관리 기능**을 분리·모듈화한  
**공통 코어 라이브러리(Common Core Library)** 입니다.

본 라이브러리는 Desktop / Web-API / Backend 전반에서 **중복되는 핵심 로직을 통합 관리**하기 위해 개발되었습니다.

---

## 🎯 설계 목적 (Design Goals)

- 📦 **공통 기능의 중앙 집중 관리**
- 🔄 Desktop / Web / Service 간 **코드 재사용성 극대화**
- 🧱 시스템 확장 시 **비즈니스 로직 분리**
- 🌐 JSON 기반 데이터 교환 구조 표준화
- ⚙️ 환경 설정 및 상수(Const) 관리 표준화
